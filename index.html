關於系統

本系統透過 GitHub Actions 每日自動執行，整合天氣與空氣品質 API，並以 Telegram 推播通勤建議。

  • 降雨機率 ≥ 60% → 提醒攜帶雨傘
  • 最高溫度 ≥ 33°C → 提醒防曬與補充水分
  • AQI ≥ 100 → 提醒配戴口罩
